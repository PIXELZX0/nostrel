결제 백엔드

키는 서버에만 저장되고 화면에는 끝 4자리만 표시됩니다. 그대로 두면 기존 값이 유지됩니다.

파일 저장소

저장 위치를 바꿔도 기존 파일은 옮겨지지 않습니다. 옮기려면 nostrel migrate-blobs <기존경로>를 실행하세요.

요금 · 릴레이 정보

짧은 이름 할증은 길이:배수 목록입니다. 예를 들어 1:20,2:10,3:5는 한 글자 이름을 도메인 가격의 20배로 팝니다. 비워두면 할증이 없습니다.

계정

초대 코드 (NIP-43)

초대 코드는 가입비를 면제합니다. 코드를 클릭하면 복사됩니다. RELAY_SECRET_KEY가 설정돼 있으면 클라이언트가 kind 28934로 직접 가입할 수도 있습니다.

그룹 (용량 공유)

멤버는 자기 계정으로 먼저 쓰고, 개인 용량이 없거나 다 쓴 뒤에만 그룹 용량을 씁니다. 한 pubkey는 그룹 하나에만 속할 수 있습니다.

NIP-05 도메인

도메인의 DNS를 이 서버로 향하게 하고, 리버스 프록시가 Host 헤더를 그대로 넘겨야 /.well-known/nostr.json이 그 도메인의 이름을 응답합니다.
